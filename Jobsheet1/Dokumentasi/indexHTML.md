# Penjelasan index.html
  1. Semua elemen dalam tag ```<head>``` tidak mempengaruhi tampilan halaman web, satu-satunya yang tampak adalah hasil dari tag ```<title>``` yang mengubah tampilan pada judul halaman web. Elemen yang ada didalam ```<head>``` kebanyakan hanya berupan= informasi tambahan seperti metadata.
  2. Beberapa tag seperti ```<header>```, ```<section>```, ```<article>```,  dan ```<footer>```, juga tidak mempengaruhi tampilan web tetapi berguna dalam SEO (search engine optimization) guna membantu mesin pencari seperti Google memahami struktur, konteks, dan hierarki konten di dalam website dengan lebih jelas. Jika SEO buruk akibat struktur kode yang berantakan, risikonya website Anda akan sulit diindeks, peringkatnya turun, dan sepi pengunjung.
  3. Tag ```<h1>``` mewakili heading utama dari sebuah halaman, sebaiknya hanya ada satu tag tersebut dalam tiap halamannya. Untuk subheading lainya tidak masalah digunakan berulang kali mulai ```<h2>``` sampai ```<h6>```. Untuk teks biasa menggunakan
  4. Tag ```<ul>``` digunakan untuk membuat list tidak bernomor/tidak berurutan. Didalamnya terdapat tag ```<li>``` yang mewakili setiap elemen dalam listnya.
  5. ```<a href=..>``` digunakan untuk berpindah halaman ketika diclick. Jika halaman yang dituju tidak ditemukan akan html menghasilkan error. Contoh saya belum membuah halaman buku/list.html maka akan error karena halaman tidak ditemukan
  6. Beberapa tag formatting dapat memanipulasi atau memberikan style pada sebuah text. seperti tag ```<sup>``` untuk membuat superscript, ataupun ```<u>``` untuk underline
  7. Kita bisa menggunakan tanda & dan diikuti oleh kode atau angka khusus untuk menghasilkan karakter dan emoji tertentu
