# Penjelasan buku/list.html
  1. Disini kita belajar untuk membuat tabel, dengan menggunakan beberapa tag berikut dan fungsinya

        | Tag | Kegunaan |
        |---|---|
        | ```<table>```| Digunakan untuk membuat struktur terluar tabel
        | ```<thead>```| Membuat kepala tabel yang nantinya berisi nama-nama kolom
        | ```<tbody>```| Bagian isi tabel yang nantinya berisi baris-baris data
        | ```<tbody>```| Bagian isi tabel yang nantinya berisi baris-baris data
        | ```<tr>```| Mendefinisikan sebuah baris
        | ```<th>```| Mengisi sel untuk judul kolom, secara default teks menjadi bold
        | ```<tr>```| Mengisi sel untuk judul kolom, secara default teks menjadi bold
        | ```<td>```| Mengisi sel untuk data dalam tabel

  2. Atribut rowspan dan colspan, digunakan untuk menggabungkan dua kolom atau dua baris seperti menu merge pada tabel ms word

  3. Atribut title digunakan agar saat kursor diarahkan ke tabel akan muncul text yang sama dengan title tersebut. Ini bukan atribut khusus table melainkan atribut yang dimilik oleh hampir semua tag

  4. Di setiap baris terdapat tombol hapus dan edit yang belum berfungsi dikarenakan tidak ada penanganan event dengan javascript ataupun php dan database
